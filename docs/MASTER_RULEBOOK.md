# Master Rulebook

The canonical printable rulebook is available from the running application at `/rules`. It contains the one-page table cheat sheet, Beerio utility rotation, audit worksheet, casino rules, host service sequence, and safety checklist.

## Confirmed Caps

- Starting wallet: 15 seconds
- Maximum wallet: 60 seconds
- Maximum lifetime seconds assigned to one recipient: 20 seconds
- Buy-back: one host-confirmed shot for 5 base wallet seconds
- Self-incurred drinking from lost bets: no software cap

## Core Settlement Rule

The number of seconds wagered on a losing selection is the number of drinking seconds the bettor owes. Penalty-themed props do not add a separate shot or sip.

Only credited profit may be assigned. Assignments spend that profit and count toward the recipient's lifetime 20-second defense cap. Personal bet losses, Beerio consumption, and buy-backs do not count toward that cap.
